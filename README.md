# Modelo de Linktree

Modelo de Linktree desenvolvido utilizando HTML, CSS e Tailwind CSS.

##  Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica para praticar
HTML, CSS e Tailwind CSS.

A proposta foi criar um modelo de página semelhante a um Linktree,
com perfil, imagem, descrição e botões de acesso.

Os botões são apenas demonstrativos e não direcionam para informações
pessoais ou páginas externas.

## Acesse o projeto

https://dev-hillary.github.io/modelo-linktree-tailwind/

##  Tecnologias utilizadas

- HTML5
- CSS3
- Tailwind CSS

##  Recursos

- Layout responsivo
- Imagem de perfil
- Botões estilizados
- Efeitos de interação
- Estilização com Tailwind CSS
- CSS personalizado

##  Objetivo

Praticar os conceitos de desenvolvimento front-end e a utilização
do Tailwind CSS na criação de interfaces web.
